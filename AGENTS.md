# Codex Notes

Before working on Boxedwine testing, OpenGL, Wine, D3D9, or Emscripten tasks, read:

- `docs/codex-testing-notes.md`

That file captures the local test commands, filesystem layout, Emscripten launch flow, and Boxedwine/Wine conventions used in recent debugging sessions.

Do not upload anything to boxedwine.org automatically. Prepare and test locally;
publish only when the user explicitly requests an upload.
